# Aya Elsayed — Portfolio

A personal portfolio for financial journalist and economic analyst Aya Elsayed. Built as a lightweight, accessible, responsive static website for GitHub Pages.

See the website source in `index.html`, `style.css`, and `script.js`. A GitHub Actions deployment workflow is included.

**Publication note:** The expected project Pages URL is `https://ayaseldein.github.io/aya-salah.github.io/`. In repository Settings → Pages, choose **GitHub Actions** as the publishing source.

Featured published writing links are credited according to their original masthead bylines; some selected items identify Aya as translator/editor rather than original author.
